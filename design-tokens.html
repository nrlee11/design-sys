Design Tokens

이 페이지는 우리 서비스에서 사용하는 공통 디자인 토큰과 각 토큰의 실제 CSS 값을 함께 보여줍니다.

컴포넌트 바로가기

Usage Guidelines

  • 색상과 radius는 반드시 디자인 토큰을 사용합니다.
  • 임의의 값(px, rem)을 직접 사용하지 않습니다.
  • 다크 모드는 토큰 값 변경으로만 대응합니다.
